# SkyLarkESP32

`WindowsApp/SkyLark` の縦シューティング「SKYLARK」を、Livico と同じ機体で遊べるようにしたもの。
起動したときに、ゲームで遊ぶか、機体を PC の USB ゲームパッド (ジョイスティック) にするかを選べる。
ゲームの中身 (地形、円盤、母船、天気、5 つの地方と物語、ランキング) と音は Windows 版と同じ。2.5D 表示はまだ移していない。

## 機体と配線

ESP32-S3-DevKitC-1 N16R8。液晶・SW1〜SW3・アンプは Livico と同じ配線で、液晶は**縦置き** (`include/config.h`)。

| 部品 | S3 | 備考 |
|---|---|---|
| 液晶 SCL / SDA / CS / DC / RST | 12 / 11 / 10 / 9 / 8 | ST7789 240x320。上下が逆なら `TFT_ROTATION` を 2 に |
| SW1 / SW2 / SW3 | 13 / 14 / 1 | 片側 GND |
| MAX98357A BCLK / LRC / DIN | 15 / 16 / 17 | Vin 5V |
| ジョイスティック GND / 5V | GND / **3.3V** | 5V にはつながない (VRX・VRY に 5V が出て ESP32 を壊す) |
| ジョイスティック VRX / VRY / SW | 4 / 5 / 6 | ADC1。SW は押すと GND |

## 書き込み

液晶は 2 種類あり、液晶に合わせてファーム (PlatformIO の env) を選ぶ。BL のほかの配線は同じ。

| 液晶 | ゲーム | ジョイスティックの試験 (横置きの画面) |
|---|---|---|
| BL 端子なし (Livico と同じ。色反転 true) | `game_nobl` | `joytest_nobl` |
| BL 端子あり (InfoPanel 初号機・TFT-VUMeterTester-240-320 と同じ。色反転 false、BL は **GPIO7**。3.3V に直結してもよい) | `game_bl` | `joytest_bl` |

```
pio run -e game_nobl -t upload     ゲーム (BL なしの液晶)
pio run -e game_bl -t upload       ゲーム (BL ありの液晶)
```

`pio run -t upload` や VS Code の書き込みボタンは `game_nobl` を書き込む。BL ありの液晶のときは、ステータスバーの env を `game_bl` に切り替えてから書き込む。
映らない (BL ありの液晶に `game_nobl` を書いた) ときや、色が反転して見えるときは、もう一方のファームを書き込む。
液晶へは両方とも 80MHz で送る。乱れるときは `-DTFT_SPI_HZ=40000000` を足して下げる。

書き込みもシリアルも、基板の内蔵 USB で通る。書き込めなくなったら BOOT を押したまま RESET を押して離し、書き込んだあと RESET を押す。
内蔵 USB は TinyUSB で動かしている (`ARDUINO_USB_MODE=0`)。シリアルは、PC 側が DTR を立てて開いたときだけ出る (`tools/snap.py` は立てて開く)。

## 起動の選択画面

電源を入れると「GAME」と「JOYSTICK」を選ぶ画面が出る。前回選んだほうが選ばれていて、触らなければ 3 秒でそれが始まる。

| 操作 | 動き |
|---|---|
| スティックの上下 / SW2 | 選ぶ (触ると自動では始まらなくなる) |
| SW1 / スティックの押し込み | 決める |

選んだほうは Preferences (`skylark` の `mode`) に残り、次に起動したときの最初の選択になる。

## CORNERS (玉突き)

四隅のポケットだけの玉突き。10 個の玉を全部落とすまでの打数を競う (少ないほどよい。ランキングは Preferences の `corners`)。

| 操作 | 動き |
|---|---|
| スティックを倒す | 倒した向きの反対へ打つ構え。倒した量が強さ (右のふちの目盛り)。手玉から当たる所までの案内線が出る |
| スティックから手を離す | はね戻った瞬間に打つ。ゆっくり中央へ戻すと打たない (やめる) |
| スティックを倒したまま SW1 | そのときの向きと強さで打つ (打ったあとは、スティックをいったん中央へ戻すまで次の構えにならない) |
| SW1 | スタート、名前の次の文字 |
| SW3 | 短く押すと音量、長押しで一時停止 (止めて SW2 でやめる)。デモの画面で長押しすると選択画面へ |

- 手玉を落とすと 1 打足して、手玉は元の線へ戻す。
- 作りは `src/game4.h` `game4.cpp`。台の絵は起動のときに PSRAM に描いておき、帯ごとに写して玉 (点ごとに陰影) を描く。
- 確かめる用のシリアルのコマンド: 選択画面で `1`〜`8` = その項目を選ぶ、`n` = SW1、`z` = 的玉を 1 個だけ残す、`a` = 自動で打つ (この 2 つを使った回は記録に残さない)。

## ORBIT (ピンボール)

宇宙のピンボール。ボール 3 個で点数を競う (ランキングは Preferences の `orbit`)。

| 操作 | 動き |
|---|---|
| SW1 / SW2 | 左 / 右のフリッパー。押した瞬間に、上のレーンの点いている明かりを左 / 右へずらす |
| スティックを後ろ (手前) に引いて離す | 引いた量の強さでボールを打ち出す。ゆっくり戻すと打たない |
| スティックを前へ押す | 台を揺らす。続けて押しすぎると TILT (そのボールはフリッパーが効かず、ボーナスなし) |
| SW3 | 短く押すと音量、長押しで一時停止 (止めて SW2 でやめる)。デモの画面で長押しすると選択画面へ |

- 上のレーン 3 本を全部点けると倍率 (最大 5 倍) が上がり、ボールが落ちたときのボーナスに掛かる。
- 左の彗星ターゲット 3 枚を全部倒すとジャックポットが 2000 上がり、右のブラックホールに入れると取れる。
- 打ち出して 8 秒はボールセーブ (1 ボールに 1 回)。
- 作りは `src/game5.h` `game5.cpp`。確かめる用のシリアルのコマンド: `n` = SW1、`z` = いまのボールを落とす、`a` = 自動で遊ぶ (この 2 つを使った回は記録に残さない)。

## JUKEBOX (レトロなピンボール)

アメリカの田舎のダイナーにありそうな、60〜70 年代ふうのピンボール。クリームの面に赤と青緑、クロームの手すり、くるみの木の枠、点数はリールの窓、点が入るたびにチャイム。
ボール 3 個で点数を競う (ランキングは Preferences の `jukebox`)。操作は ORBIT と同じ (SW1 / SW2 は下と真ん中のフリッパーがいっしょに動く)。

- 上のレーン (1・2・3) と左右の壁の的 (4・5) で 1〜5 を全部点けると、インレーンに SPECIAL が点く。点いているインレーンを通るとエクストラボール (SHOOT AGAIN)。
- 真ん中のキックアウトの穴に入るとダブルボーナス (もう点いていれば 5000 点)。ボーナスは落ちたときに 1000 ずつ数える。
- ボールセーブは無い (古い台のとおり)。
- 作りは `src/game6.h` `game6.cpp`。シリアルの `z` = いまのボールを落とす、`a` = 自動で遊ぶ。

## SMARTBALL (スマートボール)

温泉街や縁日の古い店にあるスマートボール。黄ばんだ板、はげた塗り、さびた釘、くすんだ真鍮の穴、ガラスの映りこみで、色あせた台にしてある。
持ち玉 30 個から始め、穴に入ると書いてある数だけ玉が出る。持ち玉も台の玉もなくなったら終わり。記録は払い出しの合計 (ランキングは Preferences の `smartball`)。

| 操作 | 動き |
|---|---|
| スティックを後ろ (手前) に引いて離す | 引いた量の強さで玉を打ち上げる。打った玉がレーンを出ると、次の玉が転がってくる (続けて打てる) |
| SW1 / SW2 | 台を左 / 右へ揺らす。続けて揺らしすぎると 3 秒打てない |
| SW3 | 短く押すと音量、長押しで一時停止 (止めて SW2 でやめる)。デモの画面で長押しすると選択画面へ |

- 穴は 11 個。上の段に 1 が 3 つ、3 が 2 つ、真ん中に 10 (上の釘で守ってある)、下の段に 1 が 5 つ。釘はまばらにしてある。でたらめに打つと 1 個あたり 0.6〜0.9 個ほど返る (自動で測った)。
- 作りは `src/game7.h` `game7.cpp`。シリアルの `z` = 持ち玉を 0 にする、`a` = 自動で遊ぶ。

## ジョイスティックのモード

機体を、PC の USB ゲームパッドにする (`ESP32/JoyStick` と同じ動き)。内蔵 USB で PC につなぐと、ゲームコントローラーとして認識される。Windows 版 SkyLark でそのまま遊べる。

| 機体 | PC |
|---|---|
| スティック | X 軸 / Y 軸 (縦置きで持ったときの向き。ゲームと同じ) |
| SW1 / SW2 / SW3 | ボタン 1 / 2 / 3 |
| スティックの押し込み | ボタン 4 |
| SW3 を 2 秒押し続ける | スティックの中央を取り直す (スティックから手を離して) |
| SW1 と SW3 を 2 秒押し続ける | 再起動して選択画面に戻る |

液晶にはスティックの位置、X / Y の値、押しているボタン、PC とつながっているかを出す。
ゲームパッドは USB が始まる前に登録しておく必要があるので、ゲームのモードでも PC からはゲームパッドが 1 つ見える (何も送らない)。

## 操作

| 操作 | 動き |
|---|---|
| ジョイスティック | 移動 (倒した量で速さが変わる) / 名前の文字を選ぶ |
| ジョイスティックを押し込む | ゆっくり動く |
| SW1 | 撃つ (押しっぱなしで連射)。スタート、絵はがきを進める、コンティニュー、名前の次の文字 |
| SW2 | 爆弾 (前の地上に落ちる。戦車を倒す)。名前の前の文字へ |
| SW3 | 一時停止 ⇔ 再開 |
| 一時停止中に SW2 | タイトルへ戻る |
| 一時停止中にスティックを左右 | 音量 (OFF / LOW / MID / HIGH) |

起動するときはスティックに触らない (そのときの位置を中央にする)。
スティックは取り付けの向きに合わせて上下と左右を入れ替えている (`config.h` の `JOY_SWAP_XY`)。向きが逆のときは、左右は `JOY_Y_INVERT`、上下は `JOY_X_INVERT` を切り替える。

- ランキング・前回の名前・音量は Preferences (名前空間 `skylark`) に残る。
- 効果音ははじめて起動したときに裏で作り (50 秒ほど。そのあいだは鳴らない音がある)、フラッシュ (LittleFS の `/sfx.bin`、1.4MB) に保存する。
  次からは起動して 1〜2 秒で読みこむ。`sound.cpp` を直してビルドしなおすと、次の起動で作りなおす。

## 作り

| ファイル | 中身 |
|---|---|
| `src/game.h` `game.cpp` | ゲームの中身 (Windows 版の `Game.cs`) |
| `src/game_arms.cpp` | 新しい円盤、弾、戦車、高射砲、爆弾 (`GameArms.cs`) |
| `src/game_story.cpp` | 物語、絵はがき、地図、湖水地方 (`GameStory.cs`) |
| `src/game_regions.cpp` | ヨークシャー・コーンウォール・高地、名所、結末 (`GameRegions.cs`) |
| `src/game_draw.cpp` | 描くところ (`GameDraw.cs`) |
| `src/gfx.h` `gfx.cpp` | 描く部品 |
| `src/sound.h` `sound.cpp` | 音の合成と I2S (`Sound.cs`) |
| `src/main.cpp` | 起動の選択画面、入力、1 秒 30 回の進行、保存 |
| `src/padmode.h` `padmode.cpp` | ジョイスティックのモード (USB ゲームパッド) |
| `test_joy/joytest.cpp` | ジョイスティックの試験 |
| `tools/snap.py` | 実機の画面を PNG にする (確かめる用) |

- 世界は 240x320 (地面 1 マス 8 点、30 列)。当たり判定・速さ・時刻表は Windows 版のまま。
- ゲームのコードは Windows 版と同じく「1.5 倍の点」(360x480) の座標で描き、`Gfx` が 2/3 にして液晶の点に直接描く。
  1.5 倍で描いてから縮めると 1 秒 4 コマしか出ないため。
  - 四角・円・線などは 2/3 の座標で液晶の点の並びのまま描く。円盤や家のように点ごとに陰影を計算する絵は、液晶の点 1 つにつき 1 点だけ計算する
  - 地面は 1 行ずつ 1.5 倍の細かさで描いて、面積で色を混ぜて縮めて描き置く
  - 文字で描いた点の絵 (羊、飛行機など) は、はじめて描くときに面積で色を混ぜて縮めた版を作って覚える
  - 文字は液晶の 6x8 の文字。大きさは 2/3 倍に丸める
- 画面は 64 行ずつ 5 本の帯に分けて描く。描きおえた帯はコア 0 のタスクが液晶へ送り、そのあいだに次の帯を描く。
- 地面の行は画面の上の外 3 行ぶん先に作り、1 枚ごとに 6 列ずつ描いておく (1 行に 15〜50ms かかるので、まとめて描くと止まる)。
  なめらかな雑音 (地面のむら、岩肌の陰影) は数点おきに計算してあいだを補う。
- 母船の本体は、液晶の点ごとの環・角度・色を最初に一度だけ計算して覚え、回る模様だけ毎回決める。
- ふだんは 1 秒 25〜30 コマ、母船の場面は 15〜19 コマ。
- Windows 版から変えたところ: 操作の案内の文字、絵はがきや地図の高さ (画面が 480 なので)、座ったブラック・シャックの目 (Windows 版では金色の目も重なっていた)、
  円盤の弾 (画面が小さいので 1.4 倍の大きさにし、夕焼けや雨の色掛けのあとに描いて鮮やかに見せる)、プロペラの音 (小さなスピーカーでジーと耳につく高い倍音を弱めた)、母船の弾の数 (6 割ほど。輪 14 → 8 発、狙い撃ち 5 → 3 発、曲がる弾 3 → 2 組)。

### 確かめる用

シリアル (内蔵 USB、921600) に 5 秒ごとに描く時間を出す。コマンド: `s` = 画面を送る、`f` = 10 秒先へ、`n` = SW1 を押したことにする、`m` = 母船の直前へ。

```
python tools/snap.py COM14 shots/a s w3 s
```
